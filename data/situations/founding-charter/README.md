# Founding charter

Extracted from the Open Hand Sanctuary's conflict between Cira's mistaken assumption and the institution's written obligation. The original sanctuary source remains executable and unchanged.

Bind `host`, `forecourt`, `shelter`, `admission_bolt` and `party` to canonical entities exported by an installed site. The host must already occupy the forecourt, the shelter must already be closed, and the bound bolt must be mounted in the forecourt. The site supplies geography, routes, the bolt's relation to the shelter, services, the host's creature/controller and `trusts(host,party)` if trusted communication is intended. The package does not manufacture beds or make the keeper trust every stranger.

`Discovery localfounding_oath` establishes a particular historical proposition, records the keeper's contrary assumption, and creates a readable charter in the forecourt. Reading changes only the reader's knowledge. Shared `tell` requires co-location, known established information and the keeper's explicit trust. The charter and proposition are exported for other situations to reference.

**Deliberate adaptation:** Cira's original authored `Pursuit honor_founders` used her bounded controller to plan an ordinary open action. This portable package does not add goals to another module's NPC controller. Instead a transparent state rule enforces the same bounded commitment: a living keeper at the forecourt who knows the charter retracts `closed(shelter)`. The rule has no effect while the keeper is dead, incapacitated or absent. It is a fixed commitment, not persuasion, general legal interpretation or autonomous planning. The particular host commitment is the package's explicit premise; do not install it on an NPC intended to reject the charter despite knowing it.

The changed closure is authoritative and persistent. Independent outcomes report open shelter, informed keeper and dead keeper. Opening by some other valid physical route can satisfy the access outcome without changing what the keeper knows. The source does not match a named player solution action.
