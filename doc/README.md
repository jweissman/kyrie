# Westernesse documentation

Documentation here is of two kinds, kept apart:
- **Reference** says what is true now. It is changed when the thing it describes changes, in the same commit.
- **History** says what was seen, decided or claimed at the time. It is never edited afterwards, except to repair a
  link. It lives under [history/](history/).

Where things stand now is said in one place, [STATUS.md](STATUS.md), and nowhere else at this level: neither this
index nor the README names a mission or a date. Every open promise is a row in one ledger,
[the register](architecture/open-register.md). `bun scripts/doc-links.ts` checks that every link here, and every
`doc/` path the code cites, finds what it names; `test/small/doc-links` holds it on every push.

## Keeping it so

- A mission writes what it decides into the reference document it changes, not only into its log. A brief, a log or
  a report goes into the mission's folder, and the folder goes to `history/missions/<n>` when the mission closes.
- STATUS.md is rewritten at a mission's start and close, and whenever something there stops being true.
- Move a document with `git mv`, then run `bun scripts/doc-links.ts --list` and repair what it names.
