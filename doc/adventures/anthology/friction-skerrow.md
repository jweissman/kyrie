# Friction met writing The Light on Skerrow Holm

*New frictions only; those already in [friction.md](friction.md) and the other friction-*.md files are not repeated. 7 November 2026.*

1. **A worktree that starts from main lacks the branch** (as friction-wrongboat 1): `git reset --hard adventure/anthology` was the first step. *Could:* a fork flag for the base.
2. **The shell sandbox refuses compound commands** in a worktree-isolated agent (`for` loops, `printf "$x"`, `&&` chains with substitutions, heredocs fed to `python3`). Every script had to be written with the file tool and run alone. *Could:* say which constructs are refused, or allow a fixed list.
3. **Each `.kyr` file is its own `Module id "Name" { }` block** and the module lists them in `module.json`; a missing `canon` entry for the region's parent (`imbar`) fails at load with an error that names the missing place, not the missing line in the manifest. *Could:* a lint hint "add canon".
4. **`placed.json` and `module.json` differ** (the placed form imports `party` and declares `Entity party`; the standalone form owns it and a `Company`). Both had to be generated by a script (`mkmod.py`) and kept in step by hand. *Could:* one manifest with a `placed:` overlay.
5. **A reserved or canonical name is found only at load.** `arrivedAt` is already a canonical measure; redefining it failed the whole bundle. *Could:* a lint listing canonical names by prefix.
6. **`Retract at(X, ?p)` needs `?p` bound in the condition**, as friction-wrongboat 7 said for Topics; the same is true in a Rule. The error names the variable but not the Rule's condition it should have come from.
7. **A Rule that says something needs `at(party, X)` or an area anchor**; four of my rules (the walk, the stair, the lamp) failed lint for that alone. The message is accurate; it took a read of the guide to see that `at <room>` counts.
8. **`Observe … as sound when …` has its order fixed** (`as sound` before `when`); the other order parses as a condition with a stray word.
9. **A rule cannot `Assert knows`**; knowledge is `Observe … teaches`. I wrote three rules before finding that.
10. **`following` persons are not `at` anywhere.** When Seddon follows Hettie down the stair his `at` is gone, so every rule on `at(orrin, lamp_room)` goes quiet, including the one that keeps the lamp full. The night had to say that explicitly (the lamp runs out while he chases) and the spec had to pass through it.
11. **A scenery Thing at a place cannot be looked at** unless it has `Tries looking.`; the recommended lint says so for the lamp. I left it as advice (the lamp room's first sentence already says it).
12. **A fog or tide keyed to the hour needs the hour of *arrival*.** A passage takes an hour, so a party that sets off at eleven arrives at twelve; my first window (thin at twelve) meant that nobody could ever be lost. The Thing's state also updates on the tick, not on the step, so `Initially Assert state(fog, thin)` made the fog thin at 11:00 even though the rule said thick. I moved the window to one to two and the initial state to thick. *Could:* a `state at hour` form, or a way to ask the clock what hour the passage ends.
13. **A spec cannot read an ending's title from the page.** The epilogue is told but not the title (as friction-wrongboat 10), and the failing assertion printed twenty kilobytes of journey. `Endings.reached(j.campaign.world)?.title` works but is not documented in the guide. *Could:* `Journey.reached`.
14. **A warned creature's patience**: the bargain for the Caller (`answer_false`) must be `Time 0`; the note in the checklist was right and I followed it.
15. **A hazard struck on entry hits once** (`mud_lost`): there is no way to say "each watch you stay in it". I used a `lostTold` flag cleared by leaving.
16. **`Speaker piers` requires Piers to be in the room**; the action that hands Piers's notice to Seddon had to be `Speaker orrin`. Found when it would not appear.
17. **A value in a Measure with no upper bound**: `callN` rises without limit; it is read only at fixed counts (2, 3, 4), so nothing breaks, but there is no way to say "stop counting".
18. **Write-only flags are easy to leave.** Ten relations had writers and no readers after the first pass; they came from conversation answers that I then did not use at night. I removed them rather than invent readers. *Could:* the lint warns on a Relation asserted but never read.
19. **A long conversation tree is a lot of text for one flag.** Six topic trees with three answers each are eighteen `Topic`s; their effects are four. *Could:* a form for "a question and its answers" that sets one measure.
20. **Waiting is one atomic step** (friction-wrongboat 16) and the tide, the lamp and the calls all happen inside it. A spec that waits `=06:30` from 19:30 takes the whole night in one step; the route files wait in pieces where it matters.
21. **The explorer script became a test fixture.** I wrote a scratch script (`test/zz-skerrow.ts`) with `!holds`, `!at`, `!show`, `!roll`; it was how every route was found. It was deleted before the commit. *Could:* `bin/kyrie play --script routes.txt` in the tool.
22. **Voices drift when the same flag has three answers.** The tics grep found `very`, `quite`, `Aye` and `says nothing` in the first draft; "Aye" is on the anachronism list but is also the first thing a lighthouse keeper says. I cut it.
