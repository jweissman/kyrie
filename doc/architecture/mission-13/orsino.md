# Mission 13: Orsino closure

The machine-readable inventory is `data/sources/orsino/inventory.json` (generated by `bun bin/orsino-registry.ts
inventory`; the human table is [`../orsino-inventory.md`](../orsino-inventory.md)). An entry's status is computed
from what Kyr has and draws, not claimed: **integrated** (met in play), **represented** (in Kyr's data, play does
not reach it or reaches it with declared omissions), **reference** (kept in the registry only, because Kyr does this
another way, each with its reason), **blocked** (Kyr would carry it but cannot yet, each with what is missing).

**2651 entries in 79 families: 1556 integrated, 204 represented, 751 reference, 140 blocked** (232 blocked when the
mission began).
